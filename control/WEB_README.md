# Mechatronics-4 機器人 Web 控制與即時監控系統

本專案提供一套高科技深色主題之 Web 遠端監控與控制平台，後端採用 **FastAPI + Uvicorn + WebSocket**，前端採用單一 HTML 模板 (**Jinja2**)，提供低延遲、高靈敏度的雙向序列埠通訊控制。

---

## 🌟 核心功能特色

### 1. 📹 實時影像監控器 (MediaMTX WebRTC Stream)
* **低延遲即時視訊串流**：內嵌讀取 MediaMTX 串流影像（預設 `http://mechatronic-4-6.local:8889/live/stream/?network-caching=0`），提供第一人稱駕駛視野 (FPV)。
* **靈活檢視模式**：
  * **📐 劇院寬螢幕模式**：一鍵將影像展開至全寬度 (100% 容器寬度)，享受沉浸式駕駛體驗。
  * **⛶ 原生全螢幕模式**：支援瀏覽器原生全螢幕展示。
  * **🔄 即時重載與另開視窗**：串流重開時可一鍵快速刷新，或直接另開分頁檢視。
* **智慧 IP 自適應與設定面板**：
  * 提供「**⚡ 使用當前主機 IP**」一鍵替換功能，解決行動裝置或不支援 mDNS 網域時的連線問題。
  * 支援自訂串流網址，並自動保存至瀏覽器 `localStorage`。

### 2. 📡 即時超音波數據時時監控 (前方 & 右方)
* **雙感測器獨立顯示**：即時讀取 Arduino 每 200ms 回傳的毫米整數（`CMD_ULTRASONIC_FRONT 0x11` 與 `CMD_ULTRASONIC_RIGHT 0x12`），顯示公分 (cm) 與毫米 (mm)。
* **動態警示指示條**：
  * 🟢 **安全** (> 30 cm)
  * 🟡 **注意** (15 ~ 30 cm)
  * 🔴 **危險** (< 15 cm 障礙物過近警告)
* **2D 俯視戰術探測雷達**：以動態 SVG 呈現車體底盤與前方、右方探測波束，波束長度與顏色隨實測距離動態伸縮與變色。

### 3. 🕹️ 雙馬達操控 (虛擬搖桿 / 十字方向按鈕雙模式)
* **雙控制模式自由切換**：
  * 在操控方塊下方點選 `[ 🕹️ 虛擬搖桿 ]` 或 `[ 🎛️ 方向按鈕 ]` 即可無縫切換，亦可點擊快速切換按鈕。
* **模式 A - HTML5 Canvas 虛擬搖桿**：
  * 支援觸控拖曳 (手機 / 平板) 與滑鼠拖曳 (電腦)，具有同心圓極限與彈簧自動回中復位功能。
  * 差速混控對映：Y 軸前進/後退，X 軸左轉/右轉。
* **模式 B - 前後左右十字方向按鈕 (D-Pad)**：
  * 支援觸控與滑鼠 **「按住前進/轉向、放開即停」**，安全性高。
  * 包含中央 **「■ 停止」** 按鈕，點擊立刻煞車。
* **桌面鍵盤操作**：支援 `W` / `A` / `S` / `D` 或 方向鍵，空白鍵 (`Space`) 緊急煞車，畫面即時亮起對應按鍵與 D-Pad 指示。
* **🚨 緊急全煞停按鈕**：一鍵將雙輪全煞停。
* **動力上限限制器**：可調整 60% (150)、80% (200)、100% (255)，避免測試時暴衝。

### 4. ⚙️ 進階控制分頁 (Advanced Page)
* **單馬達獨立微調 (CMD 0x02)**：
  * 左馬達 (ID:0，Pin 9/10) 與 右馬達 (ID:1，Pin 3/11) 獨立控制。
  * 支援雙向速度滑桿 (-255 到 +255)、增減微調按鈕 (`±10`, `±50`) 與極限測試 (`+200`, `-200`)。
* **直接 HEX 指令發送**：
  * 支援輸入任意十六進位指令（例如 `AA 01 00 00 00 C8 55` 或 `01 00 C8`）。
  * 支援自動包覆起始標頭 `0xAA` 與結尾碼 `0x55`。
  * 提供快捷預設指令點擊直接套用（Ping 測試、直行、後退、原地旋轉、單馬達、繼電器等）。
* **序列埠封包日誌終端機 (Terminal Monitor)**：
  * 即時列印所有 `[TX]` 發送、`[RX]` 接收與 `[SYS]` 系統訊息。
  * 支援自動滾動與日誌清空。

### 5. ✨ 虛擬模擬模式 (Mock Mode)
* 即使在沒有連接 Arduino 硬體時，也可以點擊「✨ 模擬模式」體驗完整的 UI 互動與即時動態超音波波形。

## 🚀 環境安裝與啟動方式

### 0. 安裝必要 Python 套件
在 `control` 目錄下開啟命令提示字元或終端機，執行：
```bash
pip install -r requirements.txt
```

### 方法 1: 使用批次檔 (推薦 Windows 使用者)
直接在工作目錄雙擊執行：
```cmd
run_web.bat
```

### 方法 2: 使用 Uvicorn 指令
```bash
python -m uvicorn server:app --host 0.0.0.0 --port 8000 --reload
```

### 方法 3: 直接執行 Python
```bash
python server.py
```

伺服器啟動後，請在瀏覽器打開：
👉 **http://localhost:8000**

*(若要在同一個 Wi-Fi 網域下的手機或平板操控，可在手機瀏覽器輸入電腦的區域 IP，例如 `http://192.168.x.x:8000`)*

## 📁 檔案結構說明

```text
arduino_code/main/
├── server.py              # FastAPI 後端伺服器 (包含 WebSocket、序列埠通訊狀態機與模擬器)
├── templates/
│   └── index.html         # 單一 HTML 模板 (含 CSS、SVG 動態雷達、Canvas 搖桿與 JS)
├── run_web.bat            # 一鍵啟動批次腳本
├── src/
│   ├── main.cpp           # Arduino 主韌體
│   ├── connection.h       # Arduino 序列通訊協定解析器
│   ├── motor.h            # 單馬達與雙馬達差速驅動
│   └── Ultrasonic.h       # 超音波驅動
└── test_connection.py     # 原有命令列測試工具
```
